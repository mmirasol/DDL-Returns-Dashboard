# Customer returns: how to use the returns dashboard

**Page:** https://mmirasol.github.io/DDL-Returns-Dashboard/

Sign in with the email and password you were sent. The page opens on your own screen.

The returns dashboard replaces the returns spreadsheet. Anton enters every return here and sends each batch straight to Jerald. Alyza no longer completes or endorses batches.

| Who | What they do |
|---|---|
| Anton | Enters each returned lock, fills every detail, sends the batch to Jerald |
| Jerald | Adjusts stock in Unleashed, records the stock adjustment number, which closes the batch |
| Alyza and support | Look up any return by serial, model or customer. Read only |

## Anton

1. Click **+ New batch**, or open a batch that still says **With Anton**.
2. Click **+ Add row** for each lock, and fill in:
   - **Model / part**: the product code, for example `DDL709-FVP-7HWS`
   - **Colour**: Black, Copper, Silver, Gold, White, or n/a
   - **Qty**: starts at 1
   - **Serial number**
   - **Order no**: the customer, retailer or consignment it came from
   - **Verdict**: Good (add to stock), Scrap, or Not sure
   - **Comment**: anything Jerald or support should know
3. A blank that still needs filling is outlined in yellow. Scrap rows need no details.
4. The batch can stay open as long as you need. Everything saves as you type.
5. When every row is complete, click **Send batch to Jerald**. The button stays off until nothing outlined is left.
6. Jerald gets an email as soon as you send.
7. To change something after sending, open the batch and click **Take it back**. You can do this until Jerald closes it.

## Jerald

1. Open the email, or the page, and go to **Waiting for me**.
2. Each batch lists the locks to add back. Scrap rows are hidden, because scrap never returns to stock.
3. Make the stock adjustment in Unleashed.
4. Type the adjustment number (for example `SA-00001928`) into **Stock adjustment** and click **Mark returned to stock**. That closes the batch.
5. Closed batches stay under **Closed**.

## Alyza and support

1. Use **Search** to find a return by serial, model or customer, for example when a customer follows up on a refund.
2. **Outcome** shows Jerald's stock adjustment number, Scrapped, or where the batch is now.
3. This screen is read only.
